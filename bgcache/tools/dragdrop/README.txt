bgcache: install

  >>>  Drag DRAG_ME_INTO_MAYA.py into a Maya viewport.  <<<

1. Unzip this folder anywhere. Keep DRAG_ME_INTO_MAYA.py next to the "module" folder.
2. Start Maya (2024 or newer) and drag DRAG_ME_INTO_MAYA.py from your file browser
   into a Maya viewport (the 3D view). Choose Install.
3. Click the new bgcache button on your shelf: bgcache starts and the player opens.
   Right-click the button for Stop, Restart and Self-test.

That's the only file to use: the "module" folder is what it installs.
It installs for every Maya 2024+ on this computer, in your own Maya folder.
Later updates: in the player, Help > Check for updates. Drag the file in
again to update by hand or to uninstall. Nothing else on your computer changes.
